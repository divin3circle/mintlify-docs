<AccordionGroup>
  <Accordion title="Wallet" icon="wallet">
    A wallet is like a digital bank account you control. In XPesa, it receives
    creator payments and proves which fan paid for content.
  </Accordion>
  <Accordion title="USDC" icon="coins">
    USDC is a stablecoin designed to be worth one US dollar. XPesa uses it so
    creators can price content in dollars.
  </Accordion>
  <Accordion title="Stablecoin" icon="badge-dollar">
    A stablecoin is crypto designed not to fluctuate heavily in price. It
    matters because buyers and creators can understand the price more easily.
  </Accordion>
  <Accordion title="Blockchain" icon="block">
    A blockchain is a public record of transactions. XPesa uses it to confirm
    that a payment happened.
  </Accordion>
  <Accordion title="Avalanche" icon="mountain">
    Avalanche is the network XPesa uses for payments. It is chosen for speed,
    low fees, and reliability.
  </Accordion>
  <Accordion title="Transaction hash" icon="receipt">
    A transaction hash is a public payment receipt, such as `
    {exampleTransactionHash}`. It can be used to verify that a blockchain
    transaction happened.
  </Accordion>
  <Accordion title="Gas fees" icon="gas-pump">
    Gas fees are network costs paid to process transactions. XPesa aims to keep
    the fan payment experience simple and low-cost.
  </Accordion>
  <Accordion title="Smart contract" icon="code">
    A smart contract is an automatic agreement on a blockchain. It can move
    funds or enforce rules once conditions are met.
  </Accordion>
  <Accordion title="Embedded wallet" icon="file-signature">
    An embedded wallet is a wallet created with an easier login method like
    email. It helps new fans pay without learning wallet setup first.
  </Accordion>
  <Accordion title="Access token" icon="key">
    An access token is how XPesa tracks what a fan has paid for. It helps decide
    whether content should open.
  </Accordion>
  <Accordion title="USDC on-ramp" icon="arrow-down-to-line">
    An on-ramp is a way to buy USDC with regular money. Fans may use exchanges,
    wallet providers, or checkout funding tools.
  </Accordion>
  <Accordion title="Offramp" icon="arrow-up-from-line">
    An offramp converts crypto back to regular currency. XPesa uses an offramp
    path so creators can withdraw to M-Pesa.
  </Accordion>
  <Accordion title="Wallet address" icon="fingerprint">
    A wallet address is your public identifier on the blockchain. It can appear
    in payment records and document watermarks.
  </Accordion>
  <Accordion title="Non-custodial" icon="shield-check">
    Non-custodial means you control your funds. XPesa does not hold creator
    money in a central platform balance.
  </Accordion>
  <Accordion title="Signed URL" icon="link">
    A signed URL is a temporary secure link used to serve protected content. It
    helps avoid exposing permanent file storage URLs.
  </Accordion>
</AccordionGroup>
